# parikshalab.in

Marketing site for ParikshaLab: computer based tests, a NEET and JEE Main question bank,
QBank Studio and result reports. Plain static HTML, CSS and JavaScript, served by GitHub Pages.

## Pages
- `index.html` home
- `platform.html` exam engine tour (scroll-driven screenshots, subject tabs, exam patterns)
- `qbank.html` QBank Studio and adding your own questions
- `reports.html` result reports
- `apps.html` Android, iOS and browser, with the phone screenshot carousel
- `about.html` principles, white label, onboarding
- `contact.html` contact details and a demo form that opens WhatsApp
- `404.html` not found page

## Editing
The pages are generated by `tools/build_pages.py`, which holds the shared head, header,
footer and every page's content. Change content there and run

    python tools/build_pages.py

It rewrites all the pages above and `sitemap.xml`. Editing the `.html` files by hand also
works, but the next build will overwrite those edits.

- `styles.css` all styling. Light theme by default; every colour is a token on `:root`, and
  `:root[data-theme="dark"]` redefines them for dark. Respects reduced motion.
- `script.js` theme toggle (choice saved in the browser), nav, scroll progress, reveals,
  counters, tilt, tour, tabs, carousel, form
- `assets/shots/` screenshots as WebP (`b-*` browser at 900 and 1600 px, `p-*` framed phone)
- `website_screenshots/` the original PNGs (kept locally, not in git; the site does not load them)

## User counter
The "Users on ParikshaLab" number on the home page comes from `USER_COUNT` at the top of
`script.js` (currently 1000). Raise it there as the user base grows.
